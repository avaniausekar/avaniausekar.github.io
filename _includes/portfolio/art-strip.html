{%- comment -%} Animated line drawing of software and hardware, shown at the top of the portfolio page. Pure SVG + CSS: styles are in assets/css/jekyll-theme-chirpy.scss ("Software / hardware line art"). Each device group sets `--d`, the delay before its outline starts drawing. Class hooks: `o` = outline that draws in, `code` = lines that type in, `pop` = shapes that pop in, `late` = live details that fade in once the device is drawn. {%- endcomment -%}
